Usugami on F-Droid

Offline, ad-free PDF tools for Android, with automatic updates in your F-Droid app.

Add the repository

On your Android phone, with F-Droid, Droid-ify or Neo Store installed:

Add to F-Droid

Or in F-Droid, go to Settings → Repositories → + and enter, or scan the QR code:

@REPO_URL@

Repository fingerprint (F-Droid checks it, so you know the repository is the real one):

@FINGERPRINT@

Then search for Usugami and install the app you want. Updates arrive like for any other F-Droid app.

The apps

UsugamiEvery tool, with open-source text recognition built in for searchable PDFs and scans (English, French, Spanish, Hindi, German, Portuguese, Indonesian). About 16 MB.
Usugami LiteEvery tool except text recognition. About 4.7 MB.

Both open PDFs and documents in their own reader, turn images, camera scans, ID cards, Word, PowerPoint, Excel and EPUB files into PDFs, and split, merge, compress, annotate, sign and redact PDFs on your phone, in English, French, Spanish, Hindi, German, Brazilian Portuguese and Indonesian. No internet permission, no other permissions, no ads, no tracking.

Same apps as on GitHub

This repository serves exactly the APKs of the GitHub releases, signed with the same key, so you can switch between F-Droid, GitHub and Obtainium without reinstalling. The builds are reproducible from the source code. A listing in the main F-Droid repository is planned.
