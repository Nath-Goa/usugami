# PDFer 1.1 checklist

## Images to PDF

- [x] JPG and PNG import from Photos, Files, and shares
- [x] Preview, reorder, rotate, remove, page layout, and compression
- [x] One combined PDF or one PDF per image
- [x] Optional offline OCR: English default, Hindi selectable, searchable output

## Split PDF

- [x] Select pages by thumbnails or page numbers/ranges
- [x] Enter separate custom ranges (`1-3;5;7-9`)
- [x] Split into fixed-size chunks or one file per page
- [x] Combine selected pages/ranges or output separate files
- [x] Password input, page previews, output naming, save/share

## Merge PDF

- [x] Add PDFs, move or sort full files
- [x] Page mode: reorder, rotate, remove, reset, and preview pages
- [x] Password input, output naming, save/share

## Compress PDF

- [x] Less, Recommended, and Extreme levels
- [x] Preserve selectable text and vector drawing objects
- [x] Preserve transparency, and leave unsupported images unchanged
- [x] Keep the original when recompression would enlarge an unencrypted PDF
- [x] Password input, output naming, save/share

## Verification

- [x] JVM page-selection and image-to-PDF engine tests
- [x] Device tests for split, merge, all compression levels, protected PDFs, and English/Hindi OCR
- [x] Independent PDF parsing, text extraction, and page rendering
- [x] UI checks for split, merge page mode, save to Downloads, and JPG OCR
- [x] APK permission check: no internet or network-state permission
